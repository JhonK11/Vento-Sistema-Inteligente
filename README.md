\# VENTO – Sistema Inteligente de Control de Inventario y Demanda



\## Descripción del proyecto



VENTO es un sistema inteligente orientado a la gestión y control de inventarios y demanda, diseñado para optimizar los procesos administrativos y comerciales de bodegas, minimarkets y empresas importadoras.



El sistema busca mejorar el seguimiento de productos, el control de existencias y la toma de decisiones mediante herramientas tecnológicas.



\## Estructura del proyecto



```text

VENTO/

├── vento-backend/     # Lógica del servidor y API

├── vento-frontend/    # Interfaz de usuario

└── README.md          # Documentación del proyecto

```



\## Objetivos



\- Gestionar productos y categorías.

\- Controlar entradas y salidas de inventario.

\- Facilitar el seguimiento de existencias.

\- Apoyar la planificación y análisis de la demanda.

\- Optimizar la gestión comercial.



\## Tecnologías



\- TypeScript

\- Python

\- Otras tecnologías según los módulos implementados.
